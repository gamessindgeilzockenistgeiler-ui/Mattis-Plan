# PERFORMANCE OS // BRO EDITION – iPhone-Fix

Diese Version nutzt auf dem iPhone ein **einklappbares Seitenmenü**: Tippe oben links auf **☰ Menü**, um die Navigation einzublenden. Tippe auf den dunklen Hintergrund, drücke **×** oder wähle einen Menüpunkt, um sie wieder zu schließen. Das Menü schiebt sich von links herein und belegt nicht dauerhaft den Bildschirm. Auf Desktop bleibt die Seitenleiste ebenfalls ein- und ausblendbar.

## Auf dem iPhone starten

1. Übertrage `Performance_OS_Bro_Shred.html` auf das iPhone (z. B. iCloud Drive oder AirDrop).
2. Öffne sie in Safari. Falls iOS die lokale Datei nicht richtig ausführt, hoste sie auf einem vertrauenswürdigen HTTPS-Webspace.
3. In Safari: **Teilen → Zum Home-Bildschirm**.
4. Formulare sind für Touch angepasst; Tabellen lassen sich bei Bedarf seitlich scrollen.

## Wichtig
